# SpendWise – Smart Budget Tracker

## 1. Project Description

SpendWise is a personal budgeting web application designed to help users manage their monthly budgets, record expenses, monitor spending, and track the money they have remaining.

The application provides a simple and user-friendly dashboard that makes personal financial management easier.

## 2. Project Features

- Set a monthly budget.
- Add and record expenses.
- Categorize expenses.
- Calculate total spending automatically.
- View remaining budget.
- Monitor budget progress.
- Receive budget status messages.
- Delete individual expenses.
- Clear all expenses.
- Validate user input.

## 3. Technologies Used

- **HTML5:** Provides the structure of the application.
- **CSS3:** Provides styling and responsive layouts.
- **JavaScript:** Handles calculations, user interactions, and dynamic updates.
- **GitHub:** Stores and manages the project source code.
- **Netlify:** Hosts and deploys the live website.

## 4. Project Structure

- `index.html` – Main structure of the application.
- `style.css` – Application styling and layout.
- `script.js` – JavaScript functionality and interactions.
- `README.md` – Project documentation.
